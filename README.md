# Pocket Geology

> Your steps become rock strata, and your bad weeks become fossils.

A mobile journal that turns daily movement, location, and hydration into a layered geological core. It renders each day as a sediment stratum and marks low-energy periods as fossil gaps. One weird twist: forgetting to charge creates a visible extinction layer in your personal rock record.

## Features
- Convert step counts, hydration, and sleep into colored sediment layers
- Generate a weekly rock-core visual with depth, age, and stability
- Fossilize memorable moments as embedded artifacts in the strata
- Export a geologist's certificate describing your formation type

## Stack
- SwiftUI
- HealthKit
- Core Data
- Swift Charts

## Getting started
```
Open the Xcode project and run on an iOS 17+ simulator or device with HealthKit enabled. Grant Motion & Fitness, HealthKit, and Location permissions, then add daily steps, hydration, sleep, and charging events to generate the rock core.
```
